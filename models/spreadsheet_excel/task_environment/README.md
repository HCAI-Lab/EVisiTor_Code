# KST task environment

Starting workbooks for the 14-subtask Knowledge Simulation Task in Excel. These
are the interface files the instructions in Supplementary Appendix F refer to
("open normalization.xlsx"); they contain no participant data.

- `normalization.xlsx` — the file used in the reported runs. Sheet `Blank` is
  the initial state participants and the model start from; sheet `Complete`
  holds the target end state.
- `normalization-excel-tasks-v2.xlsx` — the same workbook plus the
  `Tasks-detailed`, `Excel`, and `Notes` sheets used while authoring the task
  list.

The Windows generalization-probe environment files (`budget.xlsx`, the `Logs`
folder, `report.docx`) belong to the Paradigm Shift AI dataset and are not
redistributed here; see `models/windows_tasks/` for the `unique_data_id` of each
recording.
